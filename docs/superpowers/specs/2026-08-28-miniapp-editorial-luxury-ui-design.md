# AI素材助手小程序浅色轻奢 UI 设计

## 目标

在不改变解析、保存、点数与导航功能的前提下，将当前“软紫卡片”视觉升级为更成熟的素材编辑工具：安静、精致、有品牌识别，但不使用廉价渐变或过多装饰。

## 方向选择

| 方向 | 特征 | 结论 |
| --- | --- | --- |
| 深色科技 | 黑底、霓虹紫、强对比 | 不适合长时间阅读正文和浏览图片 |
| 浅色轻奢（采用） | 奶油白、梅子紫、深墨字、编辑排版 | 兼顾高级感、内容阅读和图片预览 |
| 甜美紫色 | 大圆角、浅紫色块、可爱图标 | 与长期运营的专业素材工具定位不符 |

## 视觉系统

### 色彩

- 画布：羊皮纸白 `#F5F1E9`，替代冷灰背景。
- 卡片：暖象牙白 `#FFFCF7`。
- 主色：梅子紫 `#3B2747`，用于主按钮、重点数字和深色区域。
- 强调：兰花紫 `#8965A6`，只用于选中、链接和细节提示。
- 正文：墨黑 `#242027`；辅助文字：灰褐 `#7B7376`；边线：`#E8DFD7`。
- 不使用紫色渐变；以细线、留白、轻微投影建立质感。

### 字体与排版

- 标题：宋体风格衬线字，用于“AI素材助手”、页面标题、关键数字。
- 正文：系统中文无衬线字，提升小字号可读性。
- 采用编辑式层级：小型英文眉题、醒目的中文标题、简短说明；不再把每个区块都做成相同卡片。

### 形状与反馈

- 卡片圆角收敛为 20–24rpx；用细描边和低饱和阴影取代厚重悬浮感。
- 主按钮为深梅子紫实色；次级按钮为象牙白描边；标签使用低饱和纸张色。
- 图片/视频预览采用深墨相框，页码和保存控件使用半透明墨色。
- 页面装饰只保留少量纸张印记和细线，不使用漂浮大色球。

## 页面改造

### 首页

- 品牌头部改为编辑刊物式排版，突出“素材提取”价值，不堆叠平台徽章。
- 平台支持信息缩为一行可读标签；解析输入区成为页面主角。
- 点数区改为简洁数据行；空状态采用克制的细线边框。

### 记录与我的

- 标题栏采用同一眉题、标题与统计标签结构。
- 记录筛选改为纸质标签样式，记录卡降低圆角和阴影。
- “我的”点数卡改为梅子紫账本卡；兑换与服务区采用更少、更清晰的层级。

### 提取结果

- 顶栏、成功状态、素材信息与首页保持同一排版系统。
- 图集和视频都使用深墨预览相框；图文正文卡使用纸张色、细边框和更舒适的行距。
- 保存动作以一个主按钮和一个克制的次级按钮区分，避免三颗相同重量的按钮。

### 原生底部 Tab

- 保留现有原生 Tab，避免再次出现结果页与主页面导航不一致。
- 调整为暖白背景、灰褐未选中态、梅子紫选中态，降低分割线存在感。

## 技术约束与验收

- 不引入 UI 库、外部字体或图片资源；确保微信小程序离线构建稳定。
- 不修改 API、数据库或保存行为。
- 首页、记录、我的、结果页共用同一颜色变量和间距规则。
- 类型检查、小程序构建和微信开发者工具编译通过。
