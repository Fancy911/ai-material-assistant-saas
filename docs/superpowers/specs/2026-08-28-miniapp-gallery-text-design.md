# AI素材助手图文解析与保存设计

## 目标

为图文/多图链接提供区别于视频的结果体验：用户可以左右预览每张图片、单张保存或全部保存，并复制解析出的标题和正文。视频结果页继续保持现有视频预览与保存路径。

## 范围

- 支持 `IMAGE` 和 `gallery` 解析结果的图集预览与图片保存。
- 保存并展示解析标题和正文；不保存、不展示作者。
- 不改变视频下载、点数扣减、解析入口、底部 Tab 或后台管理功能。

## 数据设计

### 解析任务

为解析任务新增可为空的正文文本字段，和现有 `title` 一起持久化。

- `title`：接口返回的标题。
- `content`：接口返回的正文/描述。
- 正文从上游的常见文本字段中提取；上游未返回正文时保持为空。
- 文本字段只存在于解析任务记录中，不复制到每张图片的媒体记录，避免数据重复。

### 提供方映射

智凌返回仍以图片列表和视频列表为素材来源。提供方适配层增加正文提取，并把标题和正文一并交给解析服务保存。未知或缺失文本字段不会导致图片解析失败。

## 结果页行为

### 视频结果

- 保持视频预览、保存到相册、复制链接、返回首页和继续提取。
- 不显示图集滑动和图片批量保存控件。

### 图文/图集结果

1. 顶部保留统一的返回、标题、首页导航。
2. 预览区使用横向滑动轮播，一次显示一张图片，显示 `当前张 / 总张数` 和分页圆点。
3. 当前图片下方提供“保存本张”。
4. 图片数大于一时提供“一键保存全部”；按顺序下载和保存，显示进度，单张失败不阻断其余图片，最后汇总成功数量。
5. 标题与正文使用独立文本卡片：标题优先显示；正文存在则换行显示。
6. 文本卡提供“复制文本”，复制格式为标题、空行、正文；正文缺失时仅复制标题。
7. 若图片预览失败，仍保留保存按钮与文本卡。

## 错误处理与权限

- 保存图片沿用微信相册权限；无权限或单张下载失败时显示可理解的提示。
- 批量保存进行中禁用重复触发，避免重复下载。
- 当没有标题和正文时，隐藏文本卡而不是显示空白内容。
- 图片素材为空时仍保持当前结果页的失败提示，不额外扣点。

## 验收标准

1. 多图解析成功后可左右划动，页码与当前图片同步。
2. 用户可以保存当前图片；多图时可以一键全部保存并看到成功数量。
3. 标题与正文在解析后持久化，重新打开历史记录仍可复制。
4. 没有正文的上游结果仍能成功解析和保存图片，复制按钮仅复制标题。
5. 视频结果页不出现图集控件。
6. 数据库迁移、API 测试、小程序类型检查与构建均通过。
