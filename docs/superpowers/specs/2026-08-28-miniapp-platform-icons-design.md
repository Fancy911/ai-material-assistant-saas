# 小程序提取卡片平台图标设计

## 目标

将首页的支持平台信息并入链接提取主卡片顶部，使用真实平台图标提升识别度，并删除卡片外独立的平台展示区，使首屏更集中。

## 结构

主卡片从上至下依次为：平台图标行、提取提示与粘贴入口、链接输入面、识别状态、提取按钮。平台图标行展示豆包、抖音、小红书、微信视频号、即梦、快手，并附“支持 30+ 平台分享链接”说明。

## 资源与行为

- 图标使用本地静态资源，随小程序构建产物打包，不在用户使用时加载外部图片。
- 图标仅说明支持的平台，不承担选择或筛选功能。
- 删除卡片外的横向平台模块；最近提取区上移。
- 链接识别、粘贴、解析与点数逻辑不变。

## 验收标准

1. 首页首屏无需滚动即可看到平台图标、输入区和提取按钮。
2. 六个图标清晰、等尺寸且在小屏幕上不拥挤。
3. 小程序构建产物中包含图标资源，类型检查和小程序构建通过。
