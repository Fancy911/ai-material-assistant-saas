# 小程序柔和紫高级界面设计

## 目标

将小程序恢复为柔和紫色体系，并消除蓝色版本中留白过多、信息区零散的观感。界面应具有稳定、简约和精致的素材工具感，同时保留现有解析、预览、保存、复制和点数功能。

## 视觉原则

- 以近白紫灰为页面底色，主色使用柔和紫色 `#6F3FF5`，深紫用于少量强调。
- 紫色仅用于主要操作、重要信息与微弱的背景光感；不使用大面积渐变或高饱和色块。
- 圆角、边框与阴影用于建立层级，避免满屏独立小卡片。
- 内容区以清晰的垂直节奏组织：主任务优先，辅助信息紧凑排列。

## 首页

顶部保留简洁标题、说明和点数入口。链接提取区是首屏视觉中心：使用一张圆润、层次明确的主卡片，包含轻紫边缘光感、内层输入面、平台识别状态和整宽主按钮。它应显得完整而饱满，不依赖过多分散模块。

平台支持区使用紧凑横向图标条；最近提取区用简洁列表或精致空状态承接，不使用大片虚线框。

## 记录、我的与结果

- 记录页以轻量分段筛选和整齐素材行呈现，图片与视频有清晰但克制的类型标识。
- 我的页使用柔紫渐层权益卡作为唯一主要卡片，兑换和服务区采用简洁分隔布局。
- 结果页保留深色预览容器以衬托媒体，信息、正文和保存操作使用同一套柔紫层级；图文轮播、逐张保存、全部保存、正文复制和视频保存逻辑不变。

## 验收标准

1. 全局、原生 Tab、首页、记录、我的和结果页使用一致的柔和紫视觉令牌。
2. 首页提取主卡片在首屏内具有明确层级，输入、识别状态和主按钮易读易点。
3. 不改变 API 调用、点数扣减、解析、预览、保存或复制行为。
4. 小程序类型检查和微信小程序构建通过，并在微信开发者工具复核根页面。
