# AI素材助手小程序 AI 助手风格 UI 设计

## 定位

本小程序是面向豆包及多平台链接的素材提取助手。视觉借鉴现代 AI 助手的亲和、轻量、内容优先体验，不复刻豆包的 Logo、吉祥物、文案、图标或具体页面结构。

## 设计方向

### 采用：AI 助手素材工作台

- 大面积干净白底与浅蓝空间感；内容优先而非卡片堆叠。
- 以清透蓝作为行动色，用少量暖橙表示提醒和点数，不使用紫色作为主色。
- 输入框是首页主角；结果页像助手给出的清晰回答；历史记录和账户页像简洁的辅助面板。
- 圆润但不厚重，保留少量软边界和微小图形，避免拟物和过度装饰。

### 不采用：豆包页面复刻

- 不使用任何豆包的品牌资产、角色、专属文案或可辨识的界面结构。
- 不将产品命名、图标或色彩伪装为豆包官方产品。

## 视觉令牌

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 页面底色 | `#F7FAFF` | 微蓝白，提供轻盈空间感 |
| 表面 | `#FFFFFF` | 输入区与内容承载面 |
| 主行动 | `#2878F0` | 提取、保存、主要链接 |
| 轻强调 | `#EAF2FF` | 选中态、次级按钮、标签 |
| 暖提示 | `#F59A4A` | 点数、进度与少量提醒 |
| 主文本 | `#172033` | 清晰、可信的深蓝黑 |
| 辅助文本 | `#70809A` | 说明与弱信息 |
| 分隔线 | `#E8EEF8` | 低存在感边界 |

标题使用现有系统衬线字体以增加亲和感，正文继续使用系统中文无衬线字体。所有外部字体、图像和品牌资源均不引入。

## 页面结构

### 首页

1. 轻量助手开场：简短欢迎语、产品名与当前点数。
2. 主输入区：大尺寸、单一焦点的链接输入框，带粘贴入口与“开始提取”行动按钮。
3. 平台支持：收敛为可横向阅读的小标签，不占据首页主体。
4. 最近提取：内容流列表或简洁空状态；不使用大面积虚线卡片。

### 解析反馈

- 按钮加载态展示“正在识别链接素材…”。
- 提取成功页以清楚的成功状态和素材内容为首，避免生硬的系统状态感。

### 结果

- 顶栏使用返回、页面标题和首页入口。
- 视频与图集预览维持独立能力，但统一为干净的内容容器。
- 保存本张/全部保存为明确的主次操作；标题与正文像助手输出的内容块，复制动作贴近文本。
- 结果页不是 Tab 页面，不创建视觉上类似 Tab 的控件。

### 记录与我的

- 记录采用紧凑内容流，筛选是轻量胶囊标签，素材类型和时间保持一眼可读。
- 我的页突出点数、兑换和服务入口；信息块按使用频率排列，减少装饰性深色大卡片。

### 底部导航

- 仅保留微信原生底部 Tab：首页、记录、我的。
- 调整为白色背景、蓝色选中态、蓝灰未选中态和低对比分隔线。

## 交互与技术边界

- 不改变解析接口、数据库结构、下载/保存逻辑或点数规则。
- 使用现有 uni-app 与原生小程序组件，不添加 UI 库。
- 控制动画：只对加载、切换和按压提供短促反馈，不增加影响性能的装饰动画。

## 验收标准

1. 四个页面的色彩、字号、间距、按钮与内容容器统一为 AI 助手风格。
2. 首页的链接输入和提取操作在首屏明确可见。
3. 图文与视频的现有功能均完整保留。
4. 原生 Tab 与结果页导航层级清楚，不再出现重复或仿制 Tab。
5. 类型检查、小程序构建和微信开发者工具编译通过。
