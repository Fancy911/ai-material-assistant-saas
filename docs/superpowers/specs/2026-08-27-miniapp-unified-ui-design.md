# AI素材助手小程序统一 UI 设计

## 目标

消除首页、结果、记录、我的页面之间的视觉和导航割裂。在保持现有柔和紫色品牌感的前提下，建立可复用、轻量且适合长期维护的页面壳层。

## 设计方向

- 风格：柔和紫色的轻量创作工具；暖灰背景、白色卡片、深墨文字、单一紫色强调。
- 原则：主入口只使用微信原生底部 Tab；结果页不是 Tab 页面，不伪造第二套 Tab。
- 体验：每个页面都必须有清晰的去路、可预测的层级和一致的反馈状态。

## 信息架构与导航

| 页面 | 顶部 | 底部 | 主要离开方式 |
| --- | --- | --- | --- |
| 首页 | 品牌头部 | 原生 Tab | 解析后进入结果页；可去“我的”兑换 |
| 记录 | 统一标题栏 | 原生 Tab | 点击记录进入结果页 |
| 我的 | 统一标题栏 | 原生 Tab | 兑换、登记开通意向 |
| 结果 | 自定义“返回 / 提取结果 / 首页” | 无 Tab | 返回上页、回首页、继续提取 |

结果页的“继续提取”采用一个全宽次级操作按钮，并通过 `switchTab` 回到首页；不再展示类似 Tab 的悬浮底栏。这样用户不会误以为结果页与三个一级页面属于同一层级。

## 统一组件规则

### 页面壳层

- 暖灰背景 `#F7F8FB`；页面左右留白、圆角和卡片阴影统一。
- 所有标题使用同一字号层级：主标题、段标题、辅助说明、标签文本。
- 使用系统安全区域变量，避免自定义顶栏在带刘海设备上被遮挡。

### 原生底部 Tab

- 仅用于首页、记录、我的三个一级入口。
- 选中态为现有紫色 `#6F3FF5`，未选中态统一灰紫；背景纯白。
- 文案固定为“首页 / 记录 / 我的”，不在结果页重复实现。

### 卡片、按钮与状态

- 白色卡片使用统一圆角、细边框和克制阴影。
- 主操作为实心紫色；次级操作为浅紫或白底描边；禁用、加载、空状态采用统一色阶。
- 图标采用简单线性字符/组件，避免混杂的图标风格。

## 页面改造

### 首页

- 保留现有品牌头部、平台卡和链接解析入口。
- 调整卡片间距、按钮层级、点数区与空状态，使其与其他主页面一致。

### 记录

- 使用自定义统一顶栏，移除系统标题栏的割裂感。
- 视频/图片筛选真正可点击，视觉状态随筛选同步。
- 记录项展示平台、标题、时间、解析状态和素材类型；空状态沿用首页的柔和插画式表达。

### 我的

- 使用自定义统一顶栏。
- 保留账户、点数、兑换码、开通意向四个功能块，统一卡片和按钮样式。
- 将“账户身份—点数—兑换—开通”按使用频率排列。

### 结果

- 保留自定义安全区顶栏：返回、标题、首页。
- 保留预览、素材信息、保存、复制。
- 移除悬浮 `result-dock`；加入明确的全宽“继续提取”按钮。
- 预览失败时保留保存提示，避免用户无路可走。

## 不在本次范围

- 不更改解析 API、账号、点数规则、下载逻辑或数据库。
- 不替换为自定义原生 TabBar，不引入额外 UI 库。
- 不改变 SaaS 后台和管理端页面。

## 验收标准

1. 三个一级页面均显示同一套原生底部 Tab，视觉无差异。
2. 结果页没有底部 Tab 仿制品，但能通过返回、首页和继续提取离开。
3. 首页、记录、我的、结果四页的背景、卡片、字号、按钮和紫色色阶一致。
4. 记录筛选可用，空状态与有记录状态都清晰。
5. 小程序类型检查、构建和微信开发者工具编译通过。
